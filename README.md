## ✨ Features

- 🧁 **Click:** Click to produce new Tompouces.
- ⚙️ **Upgrades:** Purchase upgrades, Yeah, just upgrades.
- 🌐 **Browser Playable:** Play where ever and when ever you want, except if you don't have internet.

1. Open the game: [Tompoespro Game](https://GoldyDuckz.github.io/Tompoespro/)

4. Buy upgrades to automate the process, if you want.
